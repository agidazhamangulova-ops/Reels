# Reels — промо-видео и маркетинг

Репозиторий для коротких видео (Reels/TikTok) и маркетинговых материалов, в первую очередь для **Plumo**. Общение с пользователем — на русском.

## Маркетинговые навыки — использовать всегда

Для любой маркетинговой задачи сначала вызывай подходящий навык, а не пиши «с нуля»:

| Задача | Навык |
|---|---|
| Сценарий ролика, подписи, посты, хуки, тексты для лендинга | `marketing:content-creation` / `marketing:draft-content` |
| Контент-план, кампания, запуск | `marketing:campaign-plan` |
| Цепочка писем / прогрев | `marketing:email-sequence` |
| Конкуренты, позиционирование | `marketing:competitive-brief` |
| Проверка текста на голос бренда перед публикацией | `marketing:brand-review` |
| Отчёт по результатам | `marketing:performance-report` |
| Разобрать чужой ролик-референс | `watch-video:watch-video` (или ffmpeg-раскадровка) |
| Собрать / отрендерить видео | `remotion:*` (`remotion-best-practices` как точка входа) |

Перед публикацией любого текста для Plumo прогоняй его через `marketing:brand-review` с правилами бренда ниже.

## Память проекта

- `/revise-claude-md` (`.claude/commands/`) — в конце сессии предложить дописать в этот файл новые правила и выводы; применять только после согласия пользователя.

## Бренд Plumo

- **Что это:** ИИ-менеджер, который не спит. Отвечает клиентам за 2 секунды, 24/7, в WhatsApp, Instagram, Telegram и на звонки; понимает кыргызский и русский (и голосовые); передаёт менеджеру готовую заявку.
- **Рынок:** малый бизнес Кыргызстана (Бишкек), цены в сомах.
- **Цена:** 5 900 сом в месяц.
- **CTA:** «пиши «ДЕМО» в комментариях», сайт **plumo.ai**.
- **Цвета:** синий `#3352FF`, тёмно-синий фон (navy-градиент), светлый `#F4F6FF`. Никакого зелёного.
- **Логотип:** круг со смещённым «зрачком» (белый круг + синяя точка на тёмном; чёрный круг + белая точка на светлом), вордмарк `plumo` строчными.
- **Тон:** коротко, по делу, разговорно; сравнение «менеджер vs Plumo», боль «клиент написал ночью — никто не ответил».
- Цифры и интерфейс в роликах пока иллюстративные — не выдавать их за реальную статистику.

## Видео (Remotion)

- Композиции: `PulsePromo` (16:9), `PlumoPromo` (9:16), `SoftReel` (9:16, фото-рил).
- Рендер в этой среде: `npx remotion render <Id> out/<name>.mp4 --browser-executable=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`
- Шрифты лежат локально в `public/fonts` (Google Fonts из песочницы недоступны). Для кириллицы грузить `*-cyrillic-*` с `unicodeRange`.
- Перед отправкой видео — проверить контакт-лист кадров (ffmpeg `tile`), что текст не обрезан и всё читается.
- Личные фото пользователя (`public/soft/photos/`) не коммитить.
